## Retail_Store_Project
Data analysis project using SQL and Power BI 
#Tools Used 
- MYSQL - Database creation and querying
- MYSQL - Writing and running SQL
- Power BI data visualizations and DAX measures
-
## SQL Concepts
- SELECT
- JOINS (INNER JOIN, LEFT JOIN)
- Aggregate functions (SUM, COUNT, AVG)
- GROUP BY
- WHERE
- CASE
- COALESCE
- UNIONS
- Views (CREATE VIEW)

## DAX Measures
- Total Revenue 
- Total Orders
- High Value Orders

## How to Run 
1. Open MySQL Workbench
2. Run retail_store_setup.sql
3. Open retail_store_dashboard.pbix in Power BI Desktop
